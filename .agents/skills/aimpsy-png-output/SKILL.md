# AIMPSY_plot のプロット出力

このルールはリポジトリ全体のプロット作成・修正・実行に適用する。特定の分析フォルダ、地域、年、シナリオに限定しない。

- ユーザーから明示的な指示がない限り、生成・保存する成果物はPNGファイルのみとする。
- PDF、SVG、JPEG、CSV、Excel、HTML、集計表、照合結果ファイルなどを、便利さや検証目的を理由に追加しない。
- 集計・収支照合・検証はメモリ上で行い、必要な結果はコンソールまたは回答で伝える。検証用データを自動保存しない。
- 新規・修正するプロットコードの通常実行ではPNGだけを保存する。参考コードに他形式の保存処理が含まれていても、その処理を引き継がない。
- ユーザーが別形式を明示的に要求した場合は、その依頼で指定された形式と範囲に限って出力する。その例外を今後の既定動作にしない。
- 出力先やファイル構成はユーザーの指定に従う。PNGだけという指定を理由に、既存の入力データや他の分析のファイルを削除しない。

このスキルはプロットの出力形式を定める。ユーザーが依頼したコードの作成・修正、またはスキルやプロジェクト指示の整備を禁止するものではない。
