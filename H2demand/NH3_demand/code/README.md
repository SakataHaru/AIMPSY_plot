# 中国のアンモニア地域分解比較

実行（リポジトリのルートから）：

```powershell
Rscript .\H2demand\NH3_demand\code\plot.R
```

入力は隣接する `data/main/merged_output.gdx` と `data/gdx_primary/{500C,500C-NH3_R272}/2040.gdx`。出力は隣接する `output` にPNGのみ保存する。明示的な指示がない限り、PDFやCSVなどの追加ファイルは生成しない。

既存の `IntermReport/code/plot_common.R`、`data_import.R`、ローカルの `fig3_common.R` を利用する。発電構成と水素転換の描画コードは、参考の `fig1/fig1_d.R` と `fig2/fig2_d.R` をこの `code` フォルダにコピーし、中国・対象年のフィルターを変更したものを使用する。実行時のコード文字列置換は行わない。地理情報は `IntermReport/data` の座標と地域対応表を利用する。Rの gdxrrw、dplyr、tidyr、ggplot2、sf、cowplot が必要。GAMSは `C:/GAMS/win64/26.1`。

- 発電構成はCHN集計値を使用し、2020、2025、2030、2035、2040年を積み上げ面で結ぶ。階層変数を二重計上せず、内訳の合計と `Sec_Ene_Ele` を照合する。
- プライマリーの365日×4時間帯を確認し、GWの時系列を6時間×3.6e-6でEJ/年に換算する。参考コードと同様、年間時間区分 `y00` と需要の `annual` 区分も集計に含む。水素・アンモニア変換の結果はメモリ上でIAMC生産量と照合する。
- 水素転換図は参考図の変換効率と収支定義を踏襲する。今回AIM-Technology需要データは入力されていないため、最終需要はプライマリーの `dmd` を集計する。直接水素需要は `dmd` の `annual` 区分も含めて集計する。合成燃料需要はこの入力ではゼロであり、転換と直接水素需要を差し引いた残差を `Other` と表示する。これは最終消費量や未利用量の確定値ではなく、指定需要と変換のみでは説明されない収支残差である。
- 水素ノード円はFig. 3-bと同じ水素入力換算：NH3・合成燃料は転換に投入される水素量、Direct H2は `Sec_Ene_Hyd` からそれらを差し引いた残差。NH3製品の出力熱量とは異なる。今回合成燃料への転換量はゼロ。
- 地図は中国の31ノードのみ描画し、2シナリオの円面積の尺度を共通にする。送電線は順方向と逆方向の年間通過量の合計であり、容量や純輸送量ではない。水素系キャリア輸送線も描画する。線幅は順方向と逆方向を合計した年間通過量（EJ/年）を示し、シナリオ間で共通尺度とする。中国のノード間または中国のR31代表点に接続するリンクを対象とし、同一地点内の接続を除外する。表示閾値は参考Fig. 3-bと同じ0.01 EJ/年。
- 図中のノード略号は `CHN-` を除いたコード。ゼロや微小量は円を描かず位置点を示す。

CHNの発電、水電解水素、アンモニア生産の差分と増減率はコンソールに表示する。
