# 世界全体のアンモニア地域分解・道路輸送比較

実行（リポジトリのルートから）：

```powershell
Rscript .\H2demand\NH3_demand\code\plot.R
```

入力は隣接する `data/main/merged_output.gdx` と `data/gdx_primary/{500C,500C-NH3_R272_ROAD}/2050.gdx`。通常版 `500C` とアンモニア地域分解＋道路輸送ありの `500C-NH3_R272_ROAD` を比較する。出力は隣接する `output` にPNGのみ保存する。明示的な指示がない限り、PDFやCSVなどの追加ファイルは生成しない。

既存の `IntermReport/code/plot_common.R`、`data_import.R`、ローカルの `fig3_common.R` を利用する。発電構成と水素転換の描画コードはローカルの `fig1_d.R` と `fig2_d.R` を使う。地理情報・ノード円の分類は参考 `IntermReport/code/fig3/fig3_b.R` と同じ定義を用い、道路輸送リンクも表示する。Rの gdxrrw、dplyr、tidyr、ggplot2、sf、cowplot が必要。GAMSは `C:/GAMS/win64/26.1`。

- 発電構成は31地域の集計値を合計し、2020～2050年を5年刻みの積み上げ面で結ぶ。詳細ノード値やR31代表点と二重計上せず、内訳の合計と `Sec_Ene_Ele` を照合する。
- プライマリーの12代表日×24時間を両シナリオで確認し、GWの時系列を30.417時間×3.6e-6でEJ/年に換算する。係数は共通の `primary_time_weight_from_timeresol('12DAY')` を利用し、モデルの丸めに合わせる。年間時間区分 `y00` と需要の `annual` 区分もモデル出力と同じ係数で集計する。水素・アンモニア・合成燃料変換の結果はメモリ上でIAMC生産量と照合し、1%超の不一致で停止する。
- 水素転換図は参考図の変換効率と収支定義を踏襲する。AIM-Technology需要データは入力されていないため、最終需要はプライマリーの `dmd` を集計する。転換と指定需要で説明されない収支残差を `Other` と表示する。これは未利用量の確定値ではない。
- 水素ノード円はFig. 3-bと同じ水素入力換算：NH3・合成燃料は転換に投入される水素量、Direct H2は `Sec_Ene_Hyd` からそれらを差し引いた残差（負値はゼロ）。NH3製品の出力熱量とは異なる。地域間の純輸送を加味した直接消費量ではなく、輸入水素を転換するノードでは残差が負になる場合がある。負の残差の件数・規模をコンソールに表示し、図にも定義を注記する。
- 世界全体の詳細ノードとR31代表点に接続する輸送を描画し、2シナリオを上下に並べる。円面積・線幅の尺度はシナリオ間で共通とする。ローカルの `fig3_b.R` は `IntermReport/code/fig3/fig3_b.R` をコピーして使用し、参考コードの `geom_curve` による描画、凡例、R31代表点を引き継ぐ。NH3海上輸送の曲率は+0.12、合成燃料は-0.12とし、いずれも輸送元から輸送先への方向別年間輸送量を1.8 mmの矢印で示す。水素パイプラインは曲率0.08の白縁付き曲線とする。追加のNH3道路輸送も曲率0.08で描画する。パイプライン・道路・送電線は順逆方向を合計した年間通過量を示す。同一地点内の接続を除外し、キャリア輸送の表示閾値は0.01 EJ/年、ノード円の表示閾値は参考コード同様0.1 EJ/年とする。
- NH3と合成燃料の海上輸送は、参考コードと同じ逆向きの曲率で重なりを分ける。国際日付変更線を横切る曲線は経度をずらした複製を描いて地図端でクリップし、実際の輸送先に矢印を表示する。ノード略号は表示しない。

世界全体の発電、水電解水素、アンモニア生産の差分と増減率はコンソールに表示する。

`fig2_c.R` は `IntermReport/code/fig2/fig2_c.R` をベースに、水素・アンモニア・合成燃料の3パネルで年間輸送量を比較する。アンモニア棒は海上輸送（紫）とトラック輸送（橙）を積み上げる。R31代表点間のNH3リンクを海上輸送、詳細ノード間のNH3リンクをトラック輸送と判定する。参考コードと同じ順逆方向の合計年間通過量を使い、同一地点内の接続を除外し、同一R31地域内の輸送も含める。地図の0.01 EJ/年の表示閾値は適用しない。合成燃料はSYFとSYMを含める。輸送モードが不明なリンクや地域未対応ノードがあれば停止する。

輸送量グラフのみ再出力する場合：`Rscript .\H2demand\NH3_demand\code\plot.R --transport-only`
